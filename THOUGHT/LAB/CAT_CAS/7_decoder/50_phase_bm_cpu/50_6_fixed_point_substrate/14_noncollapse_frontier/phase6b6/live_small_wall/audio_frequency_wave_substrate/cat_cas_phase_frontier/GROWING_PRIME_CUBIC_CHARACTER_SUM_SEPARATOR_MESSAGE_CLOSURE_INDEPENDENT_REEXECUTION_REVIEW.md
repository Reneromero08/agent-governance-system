## Reconstructed mechanism

The accepted direct-process carrier replaces the q-cell latent-strength vector
with one exact Gaussian-or-delta message. It retains two q-cell data factors,
four message field elements at the Gaussian maximum, and a public morphism
stack. The four message elements are mixed-width: one scalar lies in F_p and
three phase exponents lie in F_q. Their bit capacities and those of the mixed
public payload are counted separately in each case.

Conditioned on one data-coordinate path, controlled cubic phases are linear
updates of the latent message exponent. Each declared latent Gaussian transform
maps the message exactly to another Gaussian or to a delta, and a later
transform maps a delta back to a Gaussian. Therefore all depth-d latent-history
sums close analytically. Final projection enumerates data paths only.

The independent oracle imports neither production nor predecessor code. It
separately reconstructs the safe-prime fields, fixtures, plans, projective
Gaussian kernels, Gaussian/delta message algebra, data-path contraction,
q-by-2q dense semantics, inverses, controls, and reuse. Production JSON is
used only as a comparison target; source is parsed only for carrier structure.

## Resource result and ceiling

This is a substantive exponent reduction, not polynomial-work closure. M175's
cache-free character graph used `8*q^(2*d)` joint paths. M176 eliminates all
latent histories and uses `8*q^d` data paths, but the data message exits the
Gaussian family under cubic phase updates. No exact bounded Airy-message
closure is supplied.

The identical classical message recurrence uses the same state and work. The
exact Rader/NTT transfer retains `2*q²` state plus counted linear scratch and
remains the polynomial-work Pareto point. The qualification runner constructs
that expanded comparison after accepted projection, so the absence of q²
state applies to the message algorithm rather than the whole test process.

The ceiling is the nine declared safe-prime pairs, the listed depths and
families, two fibers, the declared Gaussian latent fixture, direct-process
finite-field software, and auxiliary NTT modulus 998,244,353. Arbitrary latent
factors are outside the message family.

The package establishes no subquadratic-state polynomial-work closure,
machine-enforced hidden factors, CATVM custody, distinct phase resource,
computational advantage, Small Wall crossing, physical waveform or silicon
execution, replacement of physical bits with pi, or unbounded computation.
