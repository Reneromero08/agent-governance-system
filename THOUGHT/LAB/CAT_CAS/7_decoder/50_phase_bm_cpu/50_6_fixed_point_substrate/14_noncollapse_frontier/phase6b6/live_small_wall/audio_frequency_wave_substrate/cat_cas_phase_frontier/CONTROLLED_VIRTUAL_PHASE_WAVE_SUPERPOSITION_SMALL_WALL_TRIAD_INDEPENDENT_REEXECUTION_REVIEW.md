# Controlled virtual phase-wave Small Wall triad independent reexecution review

## Decision

```text
INDEPENDENTLY_VERIFIED_STRICT_SCOPE
INDEPENDENT_ORACLE_REEXECUTION
NUMERICAL_PHYSICAL_STATE_RESTORATION (IN-PLACE VIRTUAL PHASE STATE)
SNAPSHOT_RELOAD (SHAM)
NO_RESTORATION_CLAIM (DIRECT BASELINE)
```

The bounded 14-case virtual-software diagnostic is accepted at its declared
scope. “Physical state” here is the registry's numerical-state restoration
class for the borrowed complex phase coordinates; no physical waveform,
audio, oscillator, or silicon execution occurred.

## Machine change and triad

The successor leaves the exact Bluestein route. It declares one unitary DFT of
`h=q-1` coherent phase modes to be one virtual wave-propagation event, preceded
by a public quadratic phase chirp. The final boundary is a public phase-weight
functional. Chirp and DFT do not commute, so inverse reordering is applicable.

Each q=5 through q=53 case uses the same request, final response schema,
boundary, and problem instance across:

- a warm compact FFT baseline with fresh reuse;
- a snapshot-backed sham;
- an in-place virtual phase carrier with actual numerical inverse and reuse.

Only the final complex scalar is returned. The in-place result is retained
until inverse restoration finishes. This ordering is local direct-process
software, not CATVM-enforced custody.

## Independent reconstruction

The standalone oracle imports neither production nor NumPy. It reconstructs
primitive roots, multiplicative phase orbits, quadratic chirps, phase weights,
and all boundaries with explicit dense unitary DFT and inverse sums. Every
production boundary and unrelated reuse boundary agrees within the
predeclared `2e-12` tolerance. Missing, wrong, and reordered inverses and
dephasing discriminate independently.

## Restoration and reuse

The in-place path restores the same `numpy.ndarray` backing by the actual
inverse DFT followed by inverse chirp. Across all cases:

- primary restoration error is at most `6.29e-16`;
- unrelated-reuse restoration error is at most `1.24e-15`;
- 256 alternating reuse cycles accumulate at most `1.01e-13` error;
- every unrelated reused boundary matches fresh execution within `2e-12`;
- no baseline reload is used.

The sham instead creates one h-complex snapshot and reloads it after the
primary and reuse programs. Its restoration class is only `SNAPSHOT_RELOAD`.

## Resource law

The apparent one-event wave operation is not free. The accepted virtual path
requires h simultaneous complex modes, h bandwidth units, 128 bits per mode,
h carrier cells, and conservatively 2h chirp/transform temporary cells. The
primary plus unrelated reuse executes four actual NumPy FFT calls as well as
four abstract wave events. The strongest compact classical comparison is the
identical 3h in-place numerical FFT recurrence with the same four calls,
inverse, and reuse law.

The direct/fresh baseline conservatively counts 4h logical complex cells and
two FFTs. The snapshot sham counts 4h cells, two forward FFTs, and 3h complex
bytes of snapshot create-plus-two-reload traffic. Request and response byte
counts are identical across all paths. Chirp and weight arrays are procedural,
not retained plans, but their temporaries are included in the conservative
cell peaks.

Seventeen-repetition warm medians are recorded as environment-specific
diagnostics, not claim authority. The ranges were approximately 32--52 us for
fresh compact execution, 33--48 us for snapshot sham, 53--70 us for in-place
phase, and 53--69 us for the identical classical in-place recurrence. These
small-case timings do not establish asymptotic leverage. NumPy allocator and
internal FFT workspace and whole-process memory are not fully measured; that
omission further forbids a memory or runtime crossing claim.

## Controls and claim ceiling

All 14 cases pass missing inverse, wrong inverse, applicable reordered inverse,
null carrier, snapshot distinction, actual restored reuse, and dephasing
controls. Dephasing changes every tested boundary, establishing that coherence
is causally relevant to these outputs. It does not establish a resource
unavailable to compact classical software.

The result therefore rejects a Small Wall crossing for this virtual primitive:
the one-event abstraction hides linear modes, bandwidth, and precision, and
the software backend is the identical compact FFT recurrence. It establishes
no CATVM custody, physical waveform execution, distinct phase resource,
computational advantage, replacement of physical bits with pi, or unbounded
computation.
