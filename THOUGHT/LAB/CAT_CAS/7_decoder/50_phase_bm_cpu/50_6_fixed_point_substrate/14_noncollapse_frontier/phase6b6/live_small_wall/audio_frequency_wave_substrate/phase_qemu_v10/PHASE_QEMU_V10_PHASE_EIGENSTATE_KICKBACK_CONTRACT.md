### Secret-dependent reusable program state

For a fixed exact deterministic processor with program states `|p_f>`, unitarity
gives

```text
<p_f|p_g><psi|phi>
= <p'_f|p'_g><psi|U_f^dagger U_g|phi>.
```

Under exact program reuse, `p'_f=p_f`. If `<p_f|p_g>` is nonzero, then
`U_f^dagger U_g` must be a scalar identity. Nonproportional client unitaries
therefore require orthogonal exact program states.

Programs A and B are nonproportional and directly witness this theorem, so
their exact reusable program states require at least dimension two. The full
two-basis-input qutrit phase family has the three projective representatives

```text

```

and requires program dimension at least three. For a client basis of size `m`,
the exact phase family has `3^(m-1)` projective classes and requires at least
that program Hilbert dimension. Program storage, preparation, certification,
and delivery are charged resources.

This package does not materialize program states and does not execute or
measure a program-state overlap. The production payload therefore records:

```text

program_states_materialized = false
```

The zero is the theorem-required symbolic conclusion under the stated fixed
