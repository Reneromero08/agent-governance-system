## Controls

- Projection while a real port lease is resident is denied; the port is
  released, the carrier is verified, and only then is the denial returned.
- Early response, wrong momentum type, and wrong lease owner follow the same
  restore-before-denial law in the production control package.
- Missing, wrong-program, reordered noncommuting, and wrong-reflection
  inverses all leave a nonzero target before a separate exact control repair;
  each repair restores the same backing before returning a boundary-free
  denial.
- Snapshot on the in-place service and in-place execution on the snapshot
  service are denied. The snapshot sham reproduces boundary 83 but is
  classified only as `SNAPSHOT_RELOAD`.
- A null service has zero carrier cells and denies both null and in-place
  commands.
- Closing the response pipe before completion still yields restoration before
  the failed response write attempt, with zero response and stderr bytes.
