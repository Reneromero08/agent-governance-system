```text

```

streams all 74,613 occupations and retains only:


full outputs.

retained public topology integers, totaling 15,775 named logical slots. The
fixed-width logical payload totals 244,592 bits: 47,824 active numeric bits,
119,441 necklace-code bits, 61,388 bracelet-code bits, and 15,939 boundary

The topology compiler peaks at 11,072 logical integer slots, including a
17-cell transient histogram, while streaming the complete occupation family.
The public source-fixture compiler peaks at 31,878 logical integer slots, so
31,878 is the accepted full-lifecycle logical-slot peak. This distinction is
required: 15,775 is retained warm algorithm state, not the whole-lifecycle
peak.

an instrumented exact count. Python container, tuple, bisect, arbitrary-width

Against comparable named-state accounting, the result saves 90,057 slots
relative to M202 and 92,168 relative to M199. It does not reduce M202's
5,534,928 fanout candidates; it adds 5,697,720 sorted searches and the stated
comparison upper bound. The identical classical implementation has the same
storage and work law.

target, output, and scalar-port backings exactly over F103. No snapshot or
baseline reload is used. Reuse advances the restoration generation to two.
