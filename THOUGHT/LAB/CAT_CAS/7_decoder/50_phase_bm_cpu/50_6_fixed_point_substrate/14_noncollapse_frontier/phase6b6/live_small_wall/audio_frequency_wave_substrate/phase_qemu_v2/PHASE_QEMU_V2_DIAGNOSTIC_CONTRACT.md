## Public family

For even `n = 2m`, use `N = m` bosons and the fixed-number basis

```text
H(n,N) = span{|x_0 ... x_(n-1)> : sum_i x_i = N}.
```

The initial state is generated by the public formula

```text
|Omega_n> = |1010...10>.
```

The directed exchange gate is

```text
a_i^dagger -> (a_i^dagger - a_j^dagger) / sqrt(2)
a_j^dagger -> (a_i^dagger + a_j^dagger) / sqrt(2).
```

The two perfect matchings are

```text
A_n = (0,1)(2,3)...(n-2,n-1)
B_n = (0,n-1)(1,2)(3,4)...(n-3,n-2).
```

For a public edge set `E`, the nonlinear layer is

```text
K_E = exp(i*pi*sum_(i,j in E) n_i*n_j).
```

The primary transfer word is

```text
A_n -> B_n -> K_{(0,1)} -> A_n -> B_n.
```

Its inverse is the reverse public adjoint. No operation history, saved
initial state, snapshot, or answer table is required to derive it.

## Exact arithmetic law

The implementation propagates integer coefficients of homogeneous creation
polynomials. Every complete 50:50 matching contributes the same denominator
`2^(N/2)`. If an occupation has integer polynomial coefficient `c_x` after
`L` matchings, its normalized Fock probability contribution is exactly

```text
c_x^2 * product_i(x_i!) / 2^(L*N).
```

Consequently:

- norms and parity weights are exact `Fraction` values;
- no floating tolerance determines support or boundary factorization;
- central Schmidt rank is the exact rational rank of each fixed-left-number
  integer coefficient block, because the omitted Fock square-root factors are
  invertible row and column scalings.

The exact sector dimensions are

```text
D(n) = binomial(n + N - 1, N):
D(4)=10, D(6)=56, D(8)=330.
```

## Boundary and QND law

For a public nonempty proper mode subset `S`, the boundary is

```text
P_S = (-1)^(sum_(i in S) n_i).
```

QND copy, retained boundary, unlatch, inverse restoration, and reuse can
coexist only if the final carrier is an exact `P_S` eigenstate. If
both parity weights are nonzero, copying the pointer leaves the retained
boundary entangled with the carrier; unlatching the internal pointer does not
make the external result independent of the carrier.

The all-mode selector is not an accepted boundary. Fixed `N` conserves its
parity for every tested word. It is enumerated as a sham separately from the
nonempty proper selectors.

## Fixed-core and disconnected controls

The control word

```text

```

with selector `S={0,4}` is tested at `n=6` and `n=8`.

At six modes its active exchange/Kerr graph can connect every mode. At eight
modes the extra `(6,7)` matching pair is disconnected from the causal core.
Thus continued deterministic closure with bounded support or bond rank is an
explicit fixed-core control, not evidence for growing relational geometry.
Adding inactive Kerr edges to make a descriptor look connected is forbidden;
every declared nonlinear edge must change the declared boundary when ablated.
