## Atomic nonlinear transaction

The production protocol is only:

```text
HELLO

```

Every `PROJECT`, debug, dump, carrier-read, and state-detail request receives
one fixed denial. Embedded-NUL, oversized, and unknown packets receive one
fixed protocol error. The production protocol has no inverse, snapshot,
fault, carrier-disabled, coefficient, or debug selector.


```text

-> construct resident unresolved H
-> consume that actual H while constructing resident Z
```

The resident four-cell `H` is never decoded, copied, serialized, hashed, or
sent. The response contains only the public variant, restoration generation,
public plan commitment, final-boundary commitment, carrier creation count,
and five final Boolean coefficients. It is constructed and sent only after
