## Topology and phase law

For each four-particle occupation histogram on the 17-cycle, the compiler
streams the unordered pair counts at cyclic distances zero through eight.
Every signature sums to six pairs. The 285 necklace cells contain 165 distinct
pair signatures. Rotation preserves each signature, and exchange symmetry is
built into occupation counts. At least one pair of states with the same onsite
collision count receives different full distance-resolved phase exponents, so
the mechanism does not merely relabel the predecessor collision scalar.

Public weights are generated from distance, step, and program tag before
execution. Compilation does not inspect final boundaries. No per-necklace
energy table is retained.

The full pair phase and the Hermitian/Givens free module are noncommuting:
swapping their forward order changes the declared boundary by approximately
`2.86e-2`. Replacing the full interaction with collision-only phase changes it
by approximately `3.15e-2`.
