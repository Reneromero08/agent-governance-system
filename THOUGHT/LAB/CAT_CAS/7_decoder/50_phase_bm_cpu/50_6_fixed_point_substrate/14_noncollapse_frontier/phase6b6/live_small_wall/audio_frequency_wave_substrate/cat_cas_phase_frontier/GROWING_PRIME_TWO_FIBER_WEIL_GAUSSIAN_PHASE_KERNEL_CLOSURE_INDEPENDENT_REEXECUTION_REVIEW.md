## Reconstructed mechanism

Each unresolved port contains one homogeneous quadratic Weil kernel encoded
by an `SL(2,q)` matrix and one 2-by-2 fiber matrix over `F_(2q+1)`. Native
composition multiplies the symplectic charts and fiber matrices with a
projective Gauss cocycle. Public separable row/column chirp intersection is an
exact left/right unipotent update of the symplectic chart. The two ports
cross-compose noncommutatively; only four declared entries contribute to the
final scalar boundary.

The independent oracle imports no production module. It reimplements the
field construction, kernel entries, public descriptor schedule, chart
composition, chirp update, projection, inverse sequence, and carrier reuse
using separate tuple/list code. It uses the production JSON only as a
comparison target.

## Resource law, comparison, and ceiling

The resident relation chart remains 16 logical field elements across the
tested orders and depths. This is not a fixed-width material-state result:
the disclosed logical payload rises through 56, 72, 88, 104, and 120 bits as
the field grows. Accepted composition streams q phase terms per cocycle. Its
public field setup also computes one q-term Gauss scalar. The strongest
executed compact classical method stores the identical 16-element relation
chart and evaluates the cocycle by a Legendre symbol after caching that public
Gauss scalar, so it has lower warm composition work. Dense tables are the
independent semantic oracle, not the comparison baseline.

The result is limited to the nine declared safe-prime pairs, two fibers, the
two public descriptor schedules, depth at most 1024, public separable chirp
intersection, one Gaussian component per port, and direct-process Linux
software. It does not establish arbitrary Gaussian Hadamard closure,
non-Gaussian closure, additive component superposition, fixed bit width for
unbounded q, CATVM custody, a distinct phase resource, computational
advantage, a Small Wall crossing, physical waveform execution, replacement of
physical bits with pi, or unbounded catalytic computation.
