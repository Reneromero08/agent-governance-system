## Reconstructed mechanism

The production path represents a bounded central, translation-invariant
continuous-`SU(2)` kernel as a finite irreducible-character polynomial.  A
public Casimir spectral phase performs normalized-Haar composition by
multiplying coefficient `r` by `u^(r(r+2))`.  Pointwise intersection with
`1+a chi_1` uses the Clebsch-Gordan identity
`chi_r chi_1 = chi_(r-1) + chi_(r+1)`.  Alternating these two laws gives two
noncommuting consumers of one resident character port without sampling group
elements, enumerating a finite group, or expanding a relation table.

The direct-process port admits only the declared public program and owner,
rejects projection until the final cursor, projects the character polynomial
only at the `SU(2)` identity, and then reverses the same program on the same
list backing.  This is typed source-level custody, not a CATVM isolation or
machine-enforced no-smuggle result.

## Independent execution

The oracle imports no CAT_CAS module.  It evolves an ordinary polynomial in
`x=chi_1`, reconstructs `chi_r=U_r(x/2)` independently, converts between the
ordinary and Chebyshev-character bases with a triangular algorithm, performs
fusion by exact linear-polynomial multiplication and inverse fusion by exact
long division, and evaluates the final boundary at `x=2`.

For both declared families at depths `1,2,4,8,16,32`, this independent
representation reproduces every production character-state commitment,
boundary commitment, support count, character payload count and boundary
payload count.  It also reproduces the unrelated depth-19 reuse transaction.
The depth-32 primary has 34 character cells carrying 3,728,007 exact payload
bits and a 156,592-bit final boundary.  Its ordinary-polynomial oracle state
has the same 34 logical cells but carries 5,323,677 payload bits.

## Restoration and controls

Casimir phases are nonzero unit Gaussian rationals, and every fusion factor is
nonzero.  Reverse Casimir multiplication and top-down exact Clebsch-Gordan
factor division restore the two-cell source exactly.  Primary and unrelated
reuse preserve the actual list backing, restored reuse agrees with a fresh
carrier, restoration generation reaches two, and no snapshot reload or
retained inverse history is used.

Wrong owner, wrong operation type, premature projection, missing inverse,
reordered inverse, null carrier and semantic fusion perturbation controls
discriminate.  Swapping one composition/fusion pair changes both the
independent polynomial and its final boundary, so the reordered-operation
control is applicable.
